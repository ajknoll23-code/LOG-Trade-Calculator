# Research Program Status V1 — Preregistration

This research-only audit classifies each major current workstream as
`completed`, `collecting-frozen`, `blocked`, or `actionable-now`.

`actionable-now` means research can legally begin now. It never means
production deployment is authorized.

Priority is dependency-first: identity/data integrity, Fundamental Value,
trade mechanics, then the separate market-opinion lens. The audit never
changes production.
