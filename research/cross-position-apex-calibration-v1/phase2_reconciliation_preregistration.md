# Cross-Position Apex Calibration V1 — Phase 2 Reconciliation Preregistration

**Status:** `FROZEN_PRE_RECONCILIATION`

Phase 2 does not create a fourth calibration model. It reconciles the
three preseason-frozen studies already capable of explaining the
Burns/Allen apex concern:

- Position Weight V2
- Replacement Level V2
- Production V2

No coefficient is fit, selected, or deployed here. Week 1 evidence is
collection-only and cannot be used to choose a Production V2 winner.

The audit distinguishes exact current-board coefficient sensitivities
from transported diagnostic sensitivities, quantifies source-state drift
since the preseason freezes, and measures whether stacking structurally
related changes would double count the same positional-economics signal.

Passing this phase means the reconciliation is internally consistent and
can be carried forward until the preregistered calibration-review window.
It does not authorize any production change.
