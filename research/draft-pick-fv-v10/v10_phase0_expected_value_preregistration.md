# Draft Pick FV V10 — Phase 0 Preregistration

V10 replaces the V9 median/MAE-like production target with an ex-ante expected-value construct. Rounds 1–4 are estimated directly from class-balanced historical H3 O2 outcome distributions. Rounds 5–6 are a separate constrained tail extrapolation with one-factor and two-factor candidates. KTC is frozen before analysis and is used only as an external construct/scale check. YEAR_DISCOUNT is explicitly out of scope.
